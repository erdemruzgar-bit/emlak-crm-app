## Bu sayfa ne işe yarar

Yeni sözleşme oluşturma formu. Kira, satış veya komisyon kaydı; otomatik komisyon dağıtımı + ilan/müşteri durum senkronu burada başlar.

## Doldurma sırası

1. **Tip seç:** KIRA / SATIS / KOMISYON. Seçim sonrası alanlar duruma göre değişir.
2. **Taraflar:**
   - **KIRA**: Kiracı + Ev Sahibi (mevcut müşteri arama)
   - **SATIS**: Alıcı + Satıcı
   - **KOMISYON**: Tek müşteri ve karşı taraf
3. **İlan seçimi (opsiyonel ama tavsiye edilir):** İlan eklendiğinde sözleşme aktif olunca **ilan durumu otomatik senkron olur**.
4. **Tutar + Para Birimi + Tarih aralığı.**
5. **Komisyon dağılımı:** Otomatik hesaplanır; gerekirse oranları override edin.
6. **Notlar + Ekler:** Sözleşme PDF'i, makbuz, ID kopyası vs.
7. **Durum:** Çoğu zaman **Aktif** seçilir. Taslak'ta bırakırsanız otomatik senkron çalışmaz.

## Sık sorulan

- **Müşteri/Sahip alanını boş bırakabilir miyim?** Hayır. Sözleşme tarafları her zaman zorunludur.
- **İlan seçmeden komisyon kaydı tutabilir miyim?** Evet — KOMISYON tipi tek başına kullanılır.
- **Tutar hangi birimde?** Para birimi seçilebilir (TRY/USD/EUR). Sözleşmenin kendi para birimi vardır; ilan fiyatından bağımsızdır.
- **Vatandaşlık fiyatı sözleşmeye geçer mi?** Hayır, sözleşme tutarı sizin elinizdedir; ilan fiyatından kopyalanmaz. Vatandaşlık farkını dahil ederek girmeniz gerekir.
- **Aktif yaptım ama ilan değişmedi.** İlan seçilmemiş olabilir. Detaya gidip ilanı bağlayıp tekrar Aktif yapın.
