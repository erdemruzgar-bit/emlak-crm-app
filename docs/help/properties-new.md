## Bu sayfa ne işe yarar

Yeni ilan kaydı oluşturma formu. Doğru doldurulduğunda otomatik müşteri eşleştirme motoru bu ilan için ilgili müşterileri **anında** liste haline getirir.

## Doldurma sırası (önerilen)

1. **Temel bilgiler:** Başlık, **İlan Tipi** (Satılık / Kiralık / Arşiv — Ayarlar'dan genişletilebilir), **Mülk Tipi** (Daire / Villa / Arsa / İşyeri / Müstakil Ev), **Fiyat + Para Birimi**.
2. **Konum:** Şehir → İlçe → Mahalle (cascade'li). Harita ile koordinat (opsiyonel).
3. **Detay:** m², oda sayısı, banyo, kat/toplam kat, yaş, ısıtma. Doldurulan her alan eşleştirme skorunu artırır.
4. **Türkiye'ye özel:** **Tapu bilgileri** (ada/pafta/parsel, bağımsız bölüm no, kat mülkiyeti tipi).
5. **Proje/Blok:** Toplu konut projesindeyse Proje + Blok + Daire No seçin.
6. **Sahip:** Müşteri arama kutusundan seçin (opsiyonel ama tavsiye edilir).
7. **Vatandaşlığa Uygun:** Yabancıya satışta TR vatandaşlık programı için işaretleyin; **Vatandaşlık Fiyat Farkı** alanına eşiğe yetecek tutarı girin (Komisyon → Vatandaşlık Hesaplayıcı yardımcı olur).
8. **Sakin Durumu:** Sahibi Oturuyor / Kiracılı / Boş / Kapora Alındı / Sözleşme Alındı / Arşiv (Ayarlar → Sakin Durumları'ndan yeni durum eklenebilir).
9. **Görseller:** Sürükle-bırak ile yükleyin; ilk yüklediğiniz **ana görsel** olur.

## Sık sorulan

- **"Vatandaşlığa Uygun" işaretlenmedi, sorun olur mu?** Yabancıya satış ihtimali yoksa hayır. Sonradan açabilirsiniz.
- **Proje/Blok dropdown'unda projem yok.** Önce Ayarlar → Projeler'den projeyi oluşturun, sonra blokları ekleyin; bu sayfaya dönün.
- **Görsel yüklenmiyor.** Dosya 100 MB altı olmalı; JPG/PNG/WEBP/MP4 desteklenir. Tarayıcının yüklemeyi tamamlamasını bekleyin.
- **Kaydet sonrası fiyatı değiştirebilir miyim?** Evet, ilan detay → kalem ikonu (Düzenle). Fiyat değişikliği audit log'a düşer.
