# Hatırlatmalar

Müşteri, ilan, sözleşme veya randevuya bağlı zamanlı hatırlatmalar. Tarih gelince üst bardaki çan ikonunda görünür ve panelde listelenir.

## Hatırlatma kurma
**Yeni Hatırlatma** ile:
- **Başlık** (zorunlu)
- **Hedef tipi:** Müşteri / İlan / Sözleşme / Randevu / Genel
- **Hedef kaydı** seçin (eğer tip Müşteri ise müşteri listesinden arayın)
- **Tarih/saat** (zorunlu)
- **Öncelik:** Düşük / Orta / Yüksek
- **Notlar** (isteğe bağlı, detay)

## Liste
- **Bugün, Bu hafta, Gelecek, Geçmiş** sekmeleri
- Hatırlatma üstüne tıklayınca hedef kaydın detayına gider (örn. müşteri sayfasına)
- **Tamam** butonuyla kapatılır; kapatılan hatırlatma raporda kalır

## İpuçları
- Müşteri detayındaki **Sonraki takip tarihi** otomatik bir hatırlatma oluşturur
- Sözleşme bitiş tarihi yaklaşırken sistem otomatik hatırlatma açar (Faz 2'de otomasyon kurallarıyla genişletilecek)
