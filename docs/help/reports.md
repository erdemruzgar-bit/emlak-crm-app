# Raporlar

Şirket performansının ana göstergelerini tek ekranda toplayan rapor merkezi.

## Bölümler

### Dashboard özet
- Aktif müşteri, ilan, sözleşme sayıları
- Aylık trend grafikleri
- Aşama bazında müşteri dağılımı

### Danışman performansı
- Her danışmanın eklediği müşteri, ilan ve kapatılan sözleşme sayıları
- Dönem seçilebilir (son 7/30/90 gün, özel aralık)

### Kaynak analizi
- Müşterilerin hangi kanaldan (Referans / İnternet / Sahibinden / Hepsiemlak / Ofis vb.) geldiği

### Ciro raporu
- İmzalanan sözleşmelerden hesaplanan toplam ciro
- Şirket payı / danışman komisyonu kırılımı
- Aylık özet

## İpuçları
- Raporlar **canlı veriden** hesaplanır; istatistikler için ayrıca işlem gerekmez
- Çoğu grafik üzerinde fare ile detay tooltip görünür
- AGENT sadece kendi performansını görür; ADMIN/MANAGER tüm şirketi
