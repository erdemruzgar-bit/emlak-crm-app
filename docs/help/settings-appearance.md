# Görünüm Ayarları

Kullanıcı arayüzünü kişiselleştirin.

## Tema
- **Aydınlık** — varsayılan
- **Karanlık** — gece kullanımı için göze rahat
- Klavye kısayolu: **D**

## Renk
Ana renk paletini seçin (mavi, mor, yeşil vb.). Tüm sistem renkleri buna göre türetilir.

## Yazı boyutu
Küçük / Orta / Büyük — küçük ekran veya görme rahatlığı için.

## İpuçları
- Bu ayarlar **kullanıcı bazlı** — sadece kendi hesabınızı etkiler
- Tarayıcı yerel depolamasında saklanır; farklı cihazda tekrar ayarlamanız gerekebilir
