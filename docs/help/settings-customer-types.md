# Müşteri Tipleri Kataloğu

Müşterilere atanan kategori listesini (Alıcı, Satıcı, Kiracı, Ev Sahibi, Yatırımcı, vb.) düzenleyin.

## Yeni tip ekleme
- **Kod** — kısa, eşsiz, büyük harf (örn. `BUYER`, `SELLER`)
- **Etiket** — UI'da görünen isim (örn. "Alıcı")
- **Renk** — liste/kart üzerinde rozetlemek için (opsiyonel)

## Düzenle / Sil
Var olan tipler kullanılıyorsa silmek yerine **pasife** alın (kullanılan tip silinemez).

## Etkisi
Bu katalog **Müşteri Formu** üzerindeki "Müşteri Tipi" dropdown'unun kaynağıdır. Buraya eklediğiniz tip hemen formda görünür.
