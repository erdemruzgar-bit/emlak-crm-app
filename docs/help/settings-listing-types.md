# İlan Tipleri Kataloğu

İlanın türünü tanımlayan kategoriler (Satılık, Kiralık, Devren Satılık, vs.).

## Yeni tip
- **Kod** — kısa, eşsiz (örn. `SATILIK`, `KIRALIK`)
- **Etiket** — formda görünen isim
- **Renk** — kart/listede rozet için (opsiyonel)

## Etkisi
Yeni ilan formundaki **İlan Tipi** dropdown'unun kaynağıdır. Hemen formda kullanılabilir.

## Notlar
Sözleşme imzalanınca **Satılık → Satıldı** veya **Kiralık → Kiralandı** durum geçişi otomatiktir; bu katalog ile statü ayrı kavramdır.
