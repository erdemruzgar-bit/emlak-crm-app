# Sakin / Doluluk Durumları Kataloğu

İlanın operasyonel durumunu yansıtan etiketler (Sahibi Oturuyor, Kiracılı, Boş, Kapora Alındı, Sözleşme Alındı, Arşiv).

## Yeni durum
- **Kod** — kısa, eşsiz (örn. `KAPORA`)
- **Etiket** — UI'da görünen isim
- **Renk** — kart/liste rozetinde

## İlan durumu vs sakin durumu
- **İlan Durumu** (sistem) → Aktif / Satıldı / Kiralandı / Pasif — genelde sözleşmeyle değişir
- **Sakin Durumu** (operasyonel) → günlük süreç. Bu katalog onu yönetir.

İki kavram birbirinden bağımsızdır; bir ilan **Aktif** olabilir ama sakin durumu **Kapora Alındı** olabilir.
