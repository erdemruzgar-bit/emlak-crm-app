# Görevler

Kendi yapacaklarınızı veya ekip üyelerine atanmış işleri tek listede yönetin.

## Görev oluşturma
**Yeni Görev** butonuyla:
- **Başlık** (zorunlu)
- **Açıklama** (isteğe bağlı, serbest metin)
- **Öncelik:** Düşük / Orta / Yüksek
- **Durum:** Yapılacak / Devam Ediyor / Tamamlandı
- **Son tarih** (opsiyonel ama önerilir — hatırlatma için kritik)
- **Atanan kişi** (kendinize veya başkasına)

## Liste & filtreler
- **Durum** ve **öncelik** sekmeleri ile hızlı filtreleme
- **Bana atananlar / Ben atadım** ayrımı üst kısımda
- Gecikmiş görevler (son tarih bugünden önce) kırmızı vurgu

## İpuçları
- Görevi tamamlayınca **Tamamlandı** durumuna alın → istatistik raporlarında "kapatılan görev" sayılır
- ADMIN/MANAGER tüm görevleri görür ve düzenler; AGENT sadece kendi atadığı veya kendine atanan görevleri yönetir
- Görev tipi olmadığı için müşteri/ilana özel iş takibi için **Hatırlatmalar** (bağlı kayıt) modülünü tercih edin
